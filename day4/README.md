# Student Grade Manager

A Streamlit gradebook frontend backed by a FastAPI service. Enter student names and marks, calculate grades and class averages, and download the results as a CSV file.

## Features

- Add between 1 and 30 student entries; the default is 1.
- Validate marks from 0 to 100 in the API.
- Calculate letter grades using these thresholds:

  | Mark | Grade |
  | --- | --- |
  | 90-100 | A |
  | 80-89.99 | B |
  | 70-79.99 | C |
  | 60-69.99 | D |
  | Below 60 | E |

- Display the class average and average grade, plus highest and lowest marks.
- Download results as a CSV generated by the API.

## Files

- `grade_api.py`: FastAPI models, grade mapping, calculation endpoint, and CSV endpoint.
- `student_grade_manager.py`: Streamlit UI that sends entries to the API and displays its results.

## Requirements

Install the dependencies in your active Python environment:

```powershell
python -m pip install fastapi uvicorn streamlit pandas requests
```

## Run the application

Open two terminals at the repository root (`python_learning`). Start the API first:

```powershell
python -m uvicorn day4.grade_api:app --reload
```

Then start the Streamlit frontend in the second terminal:

```powershell
streamlit run day4/student_grade_manager.py
```

Streamlit opens the app in your browser. Keep the API terminal running while using the app. The frontend expects the API at `http://127.0.0.1:8000`.

## API endpoints

### `POST /grades/calculate`

Accepts one or more students and returns each grade plus the class average and average grade.

Example request:

```json
{
  "students": [
    {"name": "Ada", "mark": 95},
    {"name": "Lin", "mark": 75}
  ]
}
```

Example response:

```json
{
  "results": [
    {"Name": "Ada", "Mark": 95.0, "Grade": "A"},
    {"Name": "Lin", "Mark": 75.0, "Grade": "C"}
  ],
  "average_mark": 85.0,
  "average_grade": "B"
}
```

### `POST /grades/csv`

Accepts the same request body and returns a CSV attachment with `Name`, `Mark`, and `Grade` columns.

Interactive API documentation is available at `http://127.0.0.1:8000/docs` while the API server is running.
